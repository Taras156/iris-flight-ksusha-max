# Ирисовый полёт ✿

Отдельный сайт-игра для Ксюши. Собачка летит по волшебному небу и собирает ирисы. За 12 ирисов открывается секретное поздравление.

## Как играть

- **ПК:** пробел, стрелка ↑, W или клик по игровому полю — взлететь.
- **Телефон:** касание игрового поля или кнопка «Взлететь!».
- У прыжков ограниченный запас. За собранный ирис даётся **2 прыжка**, облако подбрасывает бесплатно.
- Собери 12 ирисов за один полёт, чтобы открыть поздравление.
- Кнопки в правом верхнем углу поля: звук и пауза.
- Рекорд хранится в браузере (localStorage).

## Как запустить

Откройте `index.html` двойным нажатием. В игре нет серверной части, внешних библиотек и обязательного подключения к интернету.

## Как опубликовать на GitHub Pages

1. Создай новый публичный репозиторий, например `iris-flight-ksusha`.
2. Загрузи туда **всё содержимое** этой папки, сохранив `index.html` в корне.
3. В GitHub открой **Settings → Pages → Build and deployment**.
4. Выбери **Deploy from a branch**, **main**, **/(root)** и нажми **Save**.
5. Сайт появится по адресу вида `https://<имя-пользователя>.github.io/iris-flight-ksusha/`.

⚠️ GitHub Pages — публичная публикация. Фото/изображение собачки в репозитории и на сайте смогут увидеть посетители.

## Что можно персонализировать

- Текст поздравления: в `game.js` найди `title: 'Ксюша, это для тебя ♡'`.
- Количество ирисов для победы: в `game.js` измени `const GOAL = 12;` (не забудь поменять текст `12` в `index.html`).
- Собачка: замени `assets/dog.webp` своим файлом того же формата.

Игра написана на HTML, CSS и чистом JavaScript и работает локально или через любой статический хостинг.
